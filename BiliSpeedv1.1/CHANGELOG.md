# 更新日志

## v1.1.0 (2026-08-22)

### 更新内容

**新功能**

1. **增减倍速快捷键**：新增"增加倍速 / 减少倍速"快捷键（默认 X / Z 键），可自定义增减倍速的步进
2. **快捷键自定义**：倍速切换、增加倍速、减少倍速的按键现在均可在设置页点击录制修改，支持单键或 Ctrl/Alt/Shift + 单键的组合键，按 Esc 取消录制
3. **倍速提示浮层**：按键调节倍速后现在会在播放器中显示当前倍速
4. **精度提升**：自定义倍速现在支持 0.01 步进（如 3.25x），范围为 0.1 - 10
5. **倍速切换独立倍速值**：新增"倍速切换值"设置（默认 3.0x），不再与长按倍速共用一个数值
6. **恢复默认设置**：设置页底部新增"恢复默认设置"按钮，两步确认后生效，自定义倍速列表保留，其余设置恢复初始状态






### Bug 修复

1. **自定义倍速选中后菜单文字不变蓝**：注入菜单项时剥离了覆盖选中色的内联样式，选中色实时读取原生选中项的颜色，与原生效果完全一致
2.**设置页控件对齐美化**：数值输入框与快捷键按键框右缘对齐、数字居中

### 删除内容

1. 删除"启用 A 键切换倍速"开关
2. 删除"将 A 键切换倍速与长按倍速分开设置"开关及其独立倍速输入框（由统一的"倍速切换值"替代）
3. 删除长按倍速功能的自定义快捷键入口（固定使用 → 键）
