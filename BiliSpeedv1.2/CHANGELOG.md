# 更新日志

## v1.2.0 (2026-08-23)

### 更新内容

**新功能**

1. **直播自动最高画质（实验性）**：进入B站直播间时自动把直播画质切换到最高档，通过模拟点击实现，特殊情况下可能会失效；默认关闭，可在设置页底部"实验性"分区开启


### Bug 修复

1. **自定义倍速显示不带小数**：菜单项、倍速浮层与设置页列表的显示格式与B站原生同步
2. **评论区输入框无法正常使用→**：已修复
3. **倍速浮窗被全屏提示遮挡**：浮窗位置上移，避开全屏时顶部的"已进入全屏模式"提示
4. **稍后再看播放页扩展完全不生效**：B站稍后再看的播放页为独立地址，这些地址不匹配原有的注入规则，导致从"稍后再看"进入播放页时扩展完全不注入。现已将这三类页面全部纳入注入范围，自定义倍速与快捷键均可正常使用，收藏夹播放页与合集播放页同样修复生效


### 性能优化与界面美化

1. **DOM 监听节流**：优化了资源开销
2. **设置保存提示优化**：所有设置的"设置已保存"提示改为固定显示在视口底部居中，修改页面任意位置的设置都无需滚动即可看到
3. **设置页快捷键框显示颜色更改**：改为与自定义倍速输入框一致的白底

## v1.1.0 (2026-08-22)

### 更新内容

**新功能**

1. **增减倍速快捷键**：新增"增加倍速 / 减少倍速"快捷键（默认 X / Z 键），可自定义增减倍速的步进
2. **快捷键自定义**：倍速切换、增加倍速、减少倍速的按键现在均可在设置页点击录制修改，支持单键或 Ctrl/Alt/Shift + 单键的组合键，按 Esc 取消录制
3. **倍速提示浮层**：按键调节倍速后现在会在播放器中显示当前倍速
4. **精度提升**：自定义倍速现在支持 0.01 步进（如 3.25x），范围为 0.1 - 10
5. **倍速切换独立倍速值**：新增"倍速切换值"设置（默认 3.0x），不再与长按倍速共用一个数值
6. **恢复默认设置**：设置页底部新增"恢复默认设置"按钮，两步确认后生效，自定义倍速列表保留，其余设置恢复初始状态






### Bug 修复

1. **自定义倍速选中后菜单文字不变蓝**：注入菜单项时剥离了覆盖选中色的内联样式，选中色实时读取原生选中项的颜色，与原生效果完全一致
2.**设置页控件对齐美化**：数值输入框与快捷键按键框右缘对齐、数字居中

### 删除内容

1. 删除"启用 A 键切换倍速"开关
2. 删除"将 A 键切换倍速与长按倍速分开设置"开关及其独立倍速输入框（由统一的"倍速切换值"替代）
3. 删除长按倍速功能的自定义快捷键入口（固定使用 → 键）
